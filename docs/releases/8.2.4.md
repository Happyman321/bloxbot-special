# BloxBot 8.2.4

- Continue an existing conversation in a fresh chat with an optional focus note.
- Carry forward a compact background briefing with useful project locations, decisions, preferences, verification results, and open questions. View the briefing without filling the transcript with a summary.
- Keep the original chat intact while the continuation waits for your next assignment. Briefings persist across app restarts, and repeated handoffs refresh the inherited context.
- Improve Studio change history with durable snapshots and more complete change details.

## Download

Download the Windows 64-bit installer, `BloxBot_8.2.4_x64-setup.exe`, from the assets below.

This release includes a Windows installer only. The installer is not code-signed.
